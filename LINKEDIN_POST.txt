We built Jobform because most AI support tools sound smart — then invent a refund.

Jobform flips that. The agent handles the conversation. Policy decides the money.

It connects to a real store (NovaShop), with real customers and real orders. Shoppers ask for help in chat or by voice. Same agent. Same rules. If money moves, it only moves after policy clears it.

You set the rules. Jobform enforces them.
